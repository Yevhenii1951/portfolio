# Portfolio — Yevhenii Riabokon

Modernes, deploytes Portfolio im Luxus-Editorial-Stil (warme Creme-, Gold- und
Kakao-Palette, Serifen-Typografie, dezente Motion-Animationen).

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- React 19, TypeScript
- [Tailwind CSS 4](https://tailwindcss.com)
- [Motion](https://motion.dev) (Scroll-Reveal, Slide-Show-Hero, Carousel)

## Inhalt

- **Hero** — Fullscreen-Bildwechsler mit Graustufen-Look und Parallax
- **Profil** — Story-Sektion mit Parallax-Hintergrund und Kennzahlen
- **Stack** — Technologien nach Bereich
- **Projekte** — Produktkarten mit Hover-Crossfade, Live-/Code-Links,
  Weitere Arbeiten
- **Werdegang** — Erfahrung, Ausbildung, Sprachen
- **Kontakt / Footer** — E-Mail, LinkedIn, GitHub, Lebenslauf (PDF)

## Lokal

```bash
npm install
npm run dev
```

## Deploy

Push ins GitHub-Repository → Vercel baut automatisch (`npm run build`).
